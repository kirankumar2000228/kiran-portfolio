# Kiran Kumar Sanivada — Portfolio

A responsive, single-page developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Customize before publishing
- Add your real LinkedIn profile URL in `index.html` (the resume did not contain a URL).
- Review all resume details for accuracy.
- Replace the resume PDF in `assets/` if you update your resume.
- Add credential URLs if you want certification cards to link to proof.

## Contact form
The contact area currently uses direct email and phone links. No backend contact form is configured, so the site does not claim to submit messages to a server.

## Publish
You can deploy this static site using GitHub Pages, Netlify or another static hosting provider. Keep the `assets` folder alongside `index.html`.


## Add your profile photo
1. Choose a clear JPG/ JPEG photo of yourself.
2. Copy it into the `assets` folder.
3. Rename the image to `profile.jpg` (exact spelling).
4. Refresh the portfolio in your browser. The photo appears in the Home section.
